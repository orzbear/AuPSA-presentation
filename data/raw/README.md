# Raw Data (`data/raw/`)

This directory holds the untouched canonical export from the Australian Parliamentary Annotation system.

## Expected Canonical File

Place the canonical export file here:

- `canonical_full_corpus_ai.csv` (~1.39 GB)

## Conventions

- **Read-Only:** Files in `data/raw/` must **never** be manually edited or overwritten by scripts.
- **Git Ignored:** All data files in this directory are excluded from Git tracking via `.gitignore`.
