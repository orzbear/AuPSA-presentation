# Exploratory Notebooks (`notebooks/`)

This directory is for interactive data exploration, prototyping, and ad-hoc checks only.

## Conventions

- **Exploratory Only:** No final statistics, tables, or figures used in presentations or publications should rely solely on a notebook.
- **Promote to Scripts:** Once an analytical workflow or visualisation is finalised, port the logic into a numbered script under `scripts/`.
- Notebook checkpoints (`.ipynb_checkpoints/`) are ignored by Git.
