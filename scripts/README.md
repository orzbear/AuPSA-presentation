# Analysis Scripts (`scripts/`)

This directory contains reproducible, numbered Python scripts that implement the full pipeline from raw data ingestion to final tables and figures.

## Naming Convention

Scripts are prefixed with a two-digit execution order number:

- `01_preprocess.py` — Validates `data/raw/canonical_full_corpus_ai.csv` and produces `data/processed/hansard_labels.parquet`, `data/processed/hansard_analysis.parquet`, and `data/processed/preprocessing_manifest.json`.
- `02_...` — Subsequent descriptive and substantive analysis scripts.

## Principles

- Every table in `outputs/tables/` and figure in `outputs/figures/` or `outputs/presentation/` must be generated by a script in this directory.
- Scripts should be idempotent and runnable from the repository root.
